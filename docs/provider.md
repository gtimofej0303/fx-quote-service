# Quote Provider

## Daleelak

| Item | Value |
| --- | --- |
| Documentation | [Daleelak API](https://getdaleelak.com/en/api) |
| Endpoint | `GET https://getdaleelak.com/api/v1/feed.json?asset=us-dollar,euro` |
| Authentication | No API key or registration. |
| Limits | About 1,000 requests per day and bursts of 240 per minute per IP. |
| Input | USD-EGP and EUR-EGP assets, using `global.value` only. |
| Output | Six directed pairs between USD, EUR and EGP. |
